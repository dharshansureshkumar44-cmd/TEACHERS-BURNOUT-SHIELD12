# 🛡️ Teacher Burnout Shield

> **Problem Statement 17 Solution**: Mitigating educator burnout by managing emotional labor, administrative overload, and after-hours digital communication boundaries with privacy-preserving institutional insights.

---

## 🌟 Overview

Teaching is an emotionally demanding profession vulnerable to administrative overload, late-night communication intrusion, and fatigue. **Teacher Burnout Shield** is an intelligent digital sanctuary designed to empower educators with daily wellness check-ins, automated after-hours communication boundaries, predictive burnout telemetry, and privacy-guaranteed institutional dashboards.

---

## ✨ Key Features & Architecture

### 1. 📝 Daily Emotional & Workload Check-In UI
* **5-Point Emotional Energy Selector**: Tracks daily emotional state (Exhausted, Drained, Steady, Energized, Thriving).
* **Administrative Time Logger**: Tracks hours spent on grading & feedback, lesson prep, and administrative/IEP meetings.
* **Natural Language Reflection Engine**: Real-time browser-based NLP sentiment analyzer detecting stress markers, fatigue triggers, and administrative overload in journal entries.
* **Micro-Break Prescription**: Recommends immediate decompression protocols based on real-time stress signals.

### 2. 📊 Burnout Risk Analyzer
* **Predictive Burnout Risk Meter**: Visual gauge (0–100 score) categorized into **LOW**, **MODERATE**, **HIGH**, and **CRITICAL** risk tiers.
* **Weekly Telemetry Charting**: Correlates administrative overtime hours with emotional depletion to flag burnout trends before crisis hits.
* **Actionable Prescriptions**: Tailored recovery steps (e.g. grading time caps, quiet hours activation).

### 3. 🛡️ After-Hours Communication Shield & AI Agent
* **Automated Boundary Hours**: Customizable quiet hours (e.g., 5:00 PM – 7:30 AM) and weekend auto-lock.
* **Context-Aware AI Response Agent**:
  * 🚨 **Emergency Safety Bypass**: Immediate alert dispatch for student medical or safety emergencies.
  * 🛡️ **Tone Transformer**: Translates hostile/demanding late-night parent emails into neutral summaries and drafts firm, polite boundary auto-replies scheduled for 8:15 AM.
  * ⏰ **Scheduled Morning Dispatch**: Automatically queues routine homework inquiries for next business morning.
* **Interactive Query Simulator**: Test incoming after-hours messages in real-time.

### 4. 🏛️ Confidential School Administration Portal
* **Systemic Overload Analytics**: Provides school leadership with department-level burnout metrics without invading teacher privacy.
* **Departmental Overload Heatmap**: Identifies faculties experiencing extreme grading burden (e.g. Humanities, Special Education) for targeted resource allocation.
* **Administrative Action Hub**: Deploy floating grading TAs, enforce campus-wide evening email locks, or grant wellness flex days.

### 5. 🔒 Zero Punitive Privacy & Access Control Hub
* **Local Storage Encryption**: Raw journal notes and personal reflection entries are stored locally on the educator's device.
* **Differential Privacy Threshold**: School administration only receives aggregate metrics when $N \ge 5$ teachers participate.
* **Anti-Punitive Governance**: Systemic safeguards prevent burnout metrics from being misused in tenure reviews or performance evaluations.

## 🛠️ Tech Stack

* **Frontend Framework**: React 18
* **Styling**: Tailwind CSS v3 with Glassmorphic Design Tokens
* **Icons**: Lucide React
* **Data Visuals & Charts**: Recharts & Custom SVG Gauge Meters
* **NLP Sentiment Engine**: Client-side Natural Language Processing & Keyword Pattern Analysis
* **Build System**: Vite / Standalone HTML

## 🚀 Getting Started

### Method 1: Instant Browser Preview (Zero Setup Required)
Double-click `index.html` or open it directly in any browser:
```bash
open index.html
```

### Method 2: Development Environment
```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev
```
